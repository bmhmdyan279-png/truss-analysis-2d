## <a name="introduction"></a> معرفی

**تحلیلگر خرپای دوبعدی** یک ابزار متن‌باز است که تحلیل استاتیکی خرپاهای مسطح را با روش اجزای محدود (روش سختی) انجام می‌دهد. این نرم‌افزار علاوه بر بارهای مکانیکی، اثر تغییر دما، خطاهای ساخت (کمبود یا اضافه طول اولیه) و پایداری کمانش اویلر را نیز در نظر می‌گیرد.

هدف از این پروژه ارائه یک هسته محاسباتی شفاف، قابل درک و توسعه‌پذیر است که بتوان از آن در آموزش، تحقیق و نمونه‌سازی اولیه استفاده کرد. بر خلاف بسته‌های تجاری که الگوریتم‌های داخلی آن‌ها پنهان است، این کد تمام مراحل تحلیل را به صورت گام‌به‌گام در دسترس قرار می‌دهد.

نسخه کنونی (v1.7.0) دارای ۶۵ تست خودکار با نرخ موفقیت ۱۰۰٪ است و موتور FEM آن بر پایه **قضیه دقیق کار و انرژی برای کرنش‌های اولیه (Clapeyron's Theorem with Initial Strains)** بازنویسی شده است.

## <a name="key-features"></a> ✨ ویژگی‌های کلیدی

- 🔬 **تحلیل FEM کامل** – روش سختی (Stiffness Method) با پشتیبانی از ماتریس‌های تنک (sparse)
- 🌡️ **اثرات حرارتی** – تغییر دمای سراسری یا محلی با ضریب انبساط حرارتی
- 📏 **خطای ساخت** – مدل‌سازی طول اولیه اضافه یا کمبود (`δL₀`)
- ⚖️ **توازن انرژی دقیق** – پیاده‌سازی کامل قضیه کلپیرون برای بارهای مکانیکی، حرارتی و ساخت به‌صورت یکپارچه
- 📐 **تحلیل کمانش اویلر** – محاسبه بار بحرانی و نسبت کمانش برای اعضای فشاری
- 📊 **چندین دستگاه واحد** – SI, SI-mm, SI-cm, Imperial با تبدیل خودکار (شامل `moment_of_inertia` با فاکتور L⁴)
- 🛡️ **حلگرهای Fail-Fast** – حذف silent failure، پرتاب استثنای ساختاریافته `TRUSS-3001` در صورت ناپایداری سازه
- 🎨 **خروجی گرافیکی** – هندسه اولیه و تغییرشکل‌یافته، نمودار انرژی
- 📝 **گزارش‌گیری جامع** – خروجی‌های CSV, JSON و Markdown
- 🧪 **پوشش تست بالا** – ۶۵ تست خودکار با CI ماتریسی (Python 3.9 تا 3.12)
- ⚙️ **انعطاف در حل** – شرایط مرزی به روش حذف مستقیم (elimination) یا پنالتی

## <a name="theory"></a> 📚 مبانی تئوری

### ماتریس سختی المان

در دستگاه مختصات محلی، ماتریس سختی یک عضو خرپا به صورت زیر است:

```
        [ 1  -1 ]
k_local = (EA/L) * [ -1  1 ]
```

برای انتقال به دستگاه مختصات سراسری از ماتریس تبدیل `T` (وابسته به زاویه عضو α) استفاده می‌شود:

```
k_global = T^T · k_local · T
```

### اثرات حرارتی

تغییر طول آزاد ناشی از تغییر دما:

```
δL_thermal = α · ΔT · L
```

نیروی محوری معادل در شرایط مقید:

```
F_thermal = EA · α · ΔT
```

### خطای ساخت

تغییر طول اولیه ناشی از خطای ساخت:

```
δL_fabrication = δL₀
```

نیروی معادل:

```
F_fabrication = EA · δL₀ / L
```

### کمانش اویلر

بار بحرانی کمانش برای عضو تحت فشار محوری:

```
P_cr = π² · E · I / (K · L)²
```

که در آن `K` ضریب طول مؤثر است (مقدار پیش‌فرض: ۱.۰). نسبت کمانش به صورت زیر تعریف می‌شود:

```
buckling_ratio = |N| / P_cr
```

اگر این نسبت از ۰.۸ بیشتر شود، هشدار کمانش فعال می‌گردد.

### اعتبارسنجی تعادل انرژی (قضیه کلپیرون با کرنش اولیه)

برای سیستم‌های دارای کرنش اولیه (بارهای حرارتی یا خطای ساخت)، فرمول استاندارد `0.5 · U^T · F` ناقص است. طبق **قضیه کلپیرون تعمیم‌یافته**، انرژی کرنشی کل برابر است با:

```
U_strain = 0.5 · U^T · F_external − U^T · F_thermal + U_pure_thermal
```

که در آن:
- `0.5 · U^T · F_external` — کار نیروهای خارجی
- `U^T · F_thermal` — کار بردار نیروی معادل حرارتی
- `U_pure_thermal = Σ 0.5 · (EA/L) · δL_free²` — انرژی کرنشی خالص ذخیره‌شده در اعضا در حالت کاملاً مقید

این موتور تعادل انرژی را با دقت **کمتر از ۱٪** در تمام سناریوها (بار مکانیکی، حرارتی خالص، ترکیبی و خطای ساخت) تضمین می‌کند.

## <a name="examples"></a> 📖 مثال‌های کاربردی

### مثال ۱: عضو منفرد تحت کشش

فایل ورودی `single_tension.json`:

```json
{
  "units": "SI",
  "nodes": [
    {"id": 1, "x": 0.0, "y": 0.0, "is_support": true},
    {"id": 2, "x": 2.0, "y": 0.0, "is_support": false}
  ],
  "elements": [
    {
      "id": 1,
      "node_i": 1, "node_j": 2,
      "A": 0.01, "E": 210e9,
      "alpha": 0.0, "delta_T": 0.0, "delta_L0": 0.0
    }
  ],
  "loads": {
    "node_forces": [{"node_id": 2, "Fx": 10000.0, "Fy": 0.0}]
  },
  "options": {
    "use_sparse": false,
    "bc_method": "elimination",
    "plot_results": false
  }
}
```

اجرا:

```bash
truss-analyze single_tension.json
```

فایل `single_tension_elements.csv` نشان می‌دهد که عضو در کشش خالص قرار دارد و نسبت کمانش صفر است.

### مثال ۲: خرپای مثلثی با اثر حرارتی

از فایل `examples/example1.json` استفاده کنید. این مثال یک خرپای مثلثی متقارن با تغییر دمای ۵۰ درجه سانتی‌گراد روی عضو مورب است. تحلیل نشان می‌دهد که نیروهای داخلی تحت اثر همزمان بار مکانیکی و حرارتی محاسبه می‌شوند و **توازن انرژی با خطای کمتر از ۰.۰۱٪ برقرار است**.

### مثال ۳: خرپای پل با خطای ساخت

فایل `examples/example2.json` یک خرپای پل ساده با خطای ساخت منفی (طول کمتر از مقدار اسمی) روی یکی از اعضا را مدل می‌کند. خروجی‌ها شامل نیروهای اضافی ناشی از این کمبود طول هستند.

## <a name="architecture"></a> 🏗️ معماری کد

### نمودار ماژول‌ها

```
main.py  →  fileio.py  →  model.py  →  assembly.py  →  solver.py  →  postprocess.py
```

### مسئولیت هر ماژول

| ماژول | وظیفه |
|--------|--------|
| `model.py` | کلاس‌های `Node`، `Element` و `TrussModel` |
| `assembly.py` | مونتاژ ماتریس سختی سراسری `K` و بردار نیرو `F` (شامل نیروهای حرارتی/ساخت) |
| `solver.py` | حل دستگاه `Ku = F` و محاسبه نتایج اعضا |
| `postprocess.py` | پس‌پردازش، اعتبارسنجی و تولید گزارش‌ها |
| `fileio.py` | خواندن/نوشتن فایل‌ها و مدیریت واحدها |

### جریان داده

1. `fileio.parse_input()` – تبدیل JSON به دیکشنری
2. `TrussModel(input_data)` – ساخت اشیاء مدل (با تبدیل خودکار واحدها)
3. `assembly.build_global_matrices()` – تولید `K` و `F` (شامل `F_thermal` و `F_fabrication`)
4. `solver.solve_displacements()` – محاسبه جابجایی‌ها `u` (با fail-fast برای ماتریس‌های منفرد)
5. `solver.calculate_element_results()` – محاسبه نیروها، انرژی، کمانش
6. `solver.calculate_total_energy()` – محاسبه انرژی کل با قضیه کلپیرون تعمیم‌یافته
7. `solver.validate_energy_simple()` – اعتبارسنجی تعادل انرژی
8. `postprocess.write_output()` – تولید خروجی‌های CSV/JSON/Markdown

## <a name="troubleshooting"></a> 🔍 عیب‌یابی

| خطا | علت محتمل | راهکار |
|------|-----------|--------|
| `TRUSS-3001: Singular matrix` | سازه ناپایدار (مکانیزم) | تکیه‌گاه‌ها را بررسی کنید یا از روش پنالتی با ضریب بزرگ استفاده کنید |
| `FileNotFoundError` | مسیر فایل ورودی اشتباه | مسیر فایل JSON را تصحیح کنید |
| `ImportError` | کتابخانه‌های لازم نصب نیستند | `pip install .` |
| `KeyError: 'nodes'` | ساختار JSON معیوب | فایل را با نمونه‌های موجود در پوشه `examples` مقایسه کنید |
| `ValueError: نوع کمیت نامعتبر` | کلید واحد ناشناخته در JSON | از واحدهای مجاز استفاده کنید: `SI`, `SI-mm`, `SI-cm`, `Imperial` |
| `buckling_warning` فعال | نسبت کمانش بیش از ۰.۸ | مقطع عضو را بزرگ‌تر انتخاب کنید یا تکیه‌گاه جانبی اضافه کنید |
| هشدار تعادل انرژی | خطای عددی در محاسبات | گزارش را بررسی کنید و در صورت تداوم، Issue ثبت کنید |
