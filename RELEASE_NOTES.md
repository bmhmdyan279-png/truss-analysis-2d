# Release Notes

Release notes are published alongside each tagged release on the
[releases page](https://github.com/bmhmdyan279-png/truss-analysis-2d/releases).

Changes accumulated since the last published release are tracked in
[CHANGELOG.md](CHANGELOG.md) under `[Unreleased]`; they are consolidated
into release notes when a new version is tagged.

---

# یادداشت‌های انتشار

یادداشت‌های هر نسخه همراه با تگ همان نسخه در
[صفحهٔ انتشارها](https://github.com/bmhmdyan279-png/truss-analysis-2d/releases)
منتشر می‌شود.

تغییرات انباشته‌شده از آخرین انتشار تاکنون در فایل
[CHANGELOG.md](CHANGELOG.md) زیر بخش `[Unreleased]` ثبت می‌شوند و هنگام
برچسب‌گذاری نسخهٔ جدید، در یادداشت‌های انتشار همان نسخه جمع‌بندی خواهند شد.
